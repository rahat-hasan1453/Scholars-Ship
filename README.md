# Scholars'ship 🎓
> Global Scholarship, Professor & Safe-Bet University Discovery Portal

HighScholar is a portal designed to help international students discover fully-funded scholarships, contact hiring professors and research labs, and match with high-acceptance safe-bet regional universities with guaranteed graduate assistantships (TA/RA).

## 🚀 Key Features

- **Unified Discovery Hub (Figma Node 60-798)**: Instant search and filtering with omnibar facets, safe-bet gems, full-ride scholarships, and open faculty openings.
- **Categorized Multi-Select Search**: 40+ academic subjects grouped across 7 major disciplines, with full keyword intelligence and live search.
- **Worldwide Country Selector**: 50+ countries with search, regional categorization, and national flag indicators.
- **Smart Profile Matcher**: Profile evaluation against CGPA, IELTS, GRE, and funding requirements.
- **Automated Cold Email Generator**: Contextual academic outreach generator with customizable templates.
- **Application Kanban Pipeline**: End-to-end status tracking from research to offer letter.
- **Chrome Extension Assistant**: One-click import for university lab postings and LinkedIn updates.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Lucide Icons
- **Database / ORM**: Prisma
- **Fonts**: Inter & Geist

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore HighScholar.
